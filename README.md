# Razovy.xyz — static one-page site

This is the intentionally minimal version of Razovy.xyz.

## Purpose
Razovy.xyz is the permanent home of Razovy on the web. It does not duplicate YouTube, run a blog, fetch feeds, use a CMS, or require routine content updates.

## Files
- `index.html` — the entire website
- `style.css` — all styling
- `razovy.jpg` — logo, identity image and favicon
- `robots.txt` — search crawler instructions
- `sitemap.xml` — one-page sitemap

There is no JavaScript, database, build system, CMS, API or package dependency.

## Publish
Upload the files in this folder to the root of the GitHub Pages repository.

If the existing repository already contains a `CNAME` file for the custom domain, keep that file when replacing the old site.

## External destinations
- YouTube: https://www.youtube.com/@RazovyRevived
- Ko-fi: https://ko-fi.com/razovy
